股票判断逻辑 v1.0

这套系统只做三件事：给定一个票，算出该在什么价位买、亏多少走、赚到哪里；每天检查这些条件有没有被触发；把结果推给你。
它不选股。选股是你的工作。

0. 一句话版本

在 20 日箱体的下沿附近买入，止损放在箱底下方 0.6 个 ATR，目标看到箱顶（T1）和箱顶上方 0.6 倍箱高（T2）。
周线没站上 EMA26 的票，只降级提示，不主动喊买。

1. 四层结构

① 数据层   东财 → 腾讯 → 新浪，三级兜底，6 小时缓存
② 定价层   箱体 + ATR    → 买点区 / 止损 / T1 / T2   （plan.py）
③ 信号层   回踩 / 突破 / 确认K / 否决                 （rules.py）
④ 执行层   仓位反推 / 推送 / 看板 / 归档              （scan.py / dashboard.py）

每一层都能单独跑、单独测。改参数只改第 2、3 层，不动其他。

2. 定价：价位是怎么算出来的

对每只票，取最近 20 个交易日：

箱体上沿 hi = max(high, 20日)
箱体下沿 lo = min(low,  20日)
箱体高度 h  = hi − lo
ATR14       = 14 日平均真实波幅

然后：

项目公式为什么
买点区lo × 1.005 ~ lo + 0.18h贴着箱底买，不回撤就不买
止损lo − 0.6 × ATR留 0.6 个 ATR 的缓冲，躲开插针
T1hi箱顶是第一道真实供给
T2hi + 0.6h突破箱体后的量度目标
突破线hi × 1.005放量站上箱顶才算突破

区间中点的盈亏比：

R:R(T1) = (hi − 区中) / (区中 − 止损)
R:R(T2) = (T2 − 区中) / (区中 − 止损)
这套规则的来历：在 118 只票、1585 笔样本上测出 +0.096R/笔（胜率 35.7%，59% 止损、21% 摸到 T1 平均 +2.5R）。这是目前唯一测出正期望的规则。

3. 信号：每天怎么判断

3.1 决策优先级（从上往下，命中就停）

┌─ 硬否决（VETO）──────────────────────────────┐
│ ① 收盘 < 失效位                              │
│ ② 收盘 < 止损                                │
│ ③ 当日跌幅 ≤ −7%                             │
│ ④ 放量跌破买点区（量 >1.4×5日均量 且 收盘 < 区下沿×0.97）│
└──────────────────────────────────────────────┘
        ↓ 没命中
┌─ 软闸门（降级）──────────────────────────────┐
│ 计划要求周线站上 EMA26，但周线收盘 < 周EMA26  │
│ → 不否决，但只有确认分 ≥ 2 才提示             │
└──────────────────────────────────────────────┘
        ↓
┌─ 突破（BREAKOUT）────────────────────────────┐
│ 收盘 ≥ 突破线  且  量 ≥ 1.3 × 5日均量        │
└──────────────────────────────────────────────┘
        ↓ 没突破
┌─ 回踩（PULLBACK / TOUCH）────────────────────┐
│ 当日最低 ≤ 买点区上沿  且  收盘 ≥ 买点区下沿  │
└──────────────────────────────────────────────┘

3.2 回踩的“确认分”（0–4 分）

信号条件含义
收阳收盘 > 开盘有人在接
缩量量 < 0.9 × 5日均量抛压衰竭
长下影(min(开,收) − 最低) / 振幅 > 0.4探底回升
反包收盘 > 昨日最高直接吃掉前一天
  • ≥ 1 分 → PULLBACK（买点区触发）
  • 0 分 → TOUCH（触及买点区，还没确认）
  • 软闸门下 必须 ≥ 2 分 才提示，否则静默

3.3 否决为什么这么设

条件防的是什么
跌破止损 / 失效位计划已经死了，不许再补
单日 ≤ −7%大阴线当天，任何买点都要重估
放量跌破买点区缩量回踩变成放量出货
周线未站上 EMA26中期趋势没修复，只做防守

4. 仓位与风险

单笔风险 = 账户 × 2.5%（= 1R）
仓位%    = 2.5% ÷ 止损距离%
单票上限 = 40%

例：止损距离 7% → 仓位 36%；止损距离 2.5% → 算出来 100%，按 40% 截断并警告“止损太近”。

铁律：

  1. 止损只能上移，永远不下移
  2. 不在否决状态下开仓
  3. 同板块不超过 2 只（避免一次全错）
  4. T1 减一半，剩余止损移到成本

5. 一天的节奏

7. 哪些经过验证，哪些没有

✅ 有数据支持

结论样本结果
箱体+ATR 定价规则1585 笔 / 118 只+0.096R/笔，胜率 35.7%
“等止跌再买”优于“下跌途中买”98 只 / 45 期弱势股里止跌比不止跌好 1.8pp/20日
触发 ≠ 该买（盈亏比随现价变化）逻辑推演现价离止损越远，R:R 越低

❌ 测过但没用

结论样本结果
加周线闸门过滤入场51 笔−2.40R（比不加还差）
浮盈 1R 移保本55 笔+0.74R（把赢家砍成平手）
“强势股回踩”选股打分49 期 × 97 只IC ≈ 0，多空 t=0.81
“弱势股止跌”当策略同上20 日超额 −0.36%

⚠️ 没验证过

  • 熊市里的表现（样本只有 1.3 年、单边上涨）
  • 隔夜跳空对开盘价成交的影响
  • 分红除权对“5 日收益”统计的干扰

8. 已知缺陷

  1. 59% 的止损率——大部分信号是错的，靠 21% 的大赢家拉正，心理上难扛
  2. R:R 是“按现价”算的——现价离买点区远时，显示 0.4R 是在说“别追”，不是规则坏了
  3. 周线 EMA 需要 26 周以上数据——次新股会显示“样本不足”
  4. 不做行业轮动——板块强弱目前靠人看
  5. 选股零贡献——四轮测试都没测出 alpha，这是最大的空白

9. 一句话总结

定价有据（+0.096R/笔），信号可复现，仓位自动算，但选股仍然靠人。
这套东西的价值是"不让你在错误的位置开仓、不让你在亏损里加仓"，
不是"告诉你买什么"。
